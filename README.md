**NEON HARBOR** — an original open-world crime game that runs entirely in the browser. You are Rook, a courier newly arrived in Port Solace, a neon-dusk port city of 49 blocks, docks and palm-lined avenues. Steal any car, run six story jobs for fixer Mama Sol against the Viper crew, take repeatable Package Rush deliveries, and outrun a witness-driven wanted system that escalates from a single star to roadblocks and officers firing at five. Traffic, pedestrians, police chases, car damage, a minimap and full HUD, synthesized engine/combat audio and a 96 BPM synthwave loop — all procedural, all offline, no network requests at runtime.

Controls: WASD drive / move, mouse camera (click to lock), F enter or steal a car, Shift sprint, Space jump / handbrake, 1 draw pistol, left mouse punch or shoot, R reload, M map, Esc pause.

## Run it

```sh
node serve.ts --port 8901
# then open http://localhost:8901 in desktop Chrome
```
